# AWS Jr. Champions 選出基準・要件

> 出典: [2026 Japan AWS Jr. Champions クライテリアのお知らせ](https://aws.amazon.com/jp/blogs/psa/2026-japan-aws-jr-champions-criteria/)
> 2027年度応募時は最新クライテリアを必ず確認すること。

## 対象者条件

- 社会人歴3年以内（2023年4月以降入社）
- APN パートナー企業所属
  - サービスパス：アドバンストティア以上
  - ソフトウェアパス：Validatedステージ以上
- 1企業ドメインにつき最大2名
- 過去の選出者は対象外（1年任期・複数年選出なし）

## 資格要件

以下をすべて満たすこと（活動期間終了日まで有効であること）：

- AWS Certified Cloud Practitioner（CLF）✅ 取得済み
- AWS Certified AI Practitioner（AIF）✅ 取得済み
- 上記以外のAWS認定を3つ以上 ✅ 取得済み（SAA/DVA/SOA/SAP/DOP）
- **合計5資格以上**（デジタルバッジの共有が証明として必要）

## 評価の3項目（各500文字以内）

| 項目 | 内容 | 記事執筆との対応 |
|---|---|---|
| **Challenge** | AWSに関して自ら実践してきた技術的挑戦 | ハンズオン記事の執筆・検証作業そのもの |
| **Influence** | コミュニティや周囲への影響・貢献 | 記事が他者の学習に役立つかどうか |
| **Output** | ブログ・登壇・勉強会・社内トレーニング等 | Qiita記事は直接ここに記載できる |

選考は「AWSエンジニアとしてのポテンシャルと自律的なオーナーシップ」による総合判断。

## 応募に必要なもの

- スポンサー情報（氏名・連絡先）
- AWS PSA の推薦状
- Japan AWS Jr. Champions Meetup への参加コミットメント

## 活動期間

**2026年度**: 2025年4月1日〜2026年3月31日
**2027年度**: おそらく 2026年4月1日〜2027年3月31日（要確認）

## 記事戦略メモ

- **Bedrockなど最新AIサービスのハンズオン記事**が3項目すべてにヒットするため最も有効
- 擬人化イラストなどの独自性はあくまで差別化の付加価値に留める
- Challenge の証明として「自分で構築・検証した内容」が含まれることが重要
