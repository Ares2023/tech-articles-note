# Tech系記事 執筆Vault

Qiita投稿用記事の執筆・調査ノート。

## フォルダ構成

```
00_AgentCore-概要/          ← 第1弾：AgentCore解説記事
  00_企画/                  ← 記事の方針・ターゲット設定
  01_調査/                  ← 技術調査メモ
  02_下書き/                ← 本文下書き
  03_成果物/                ← 最終版・投稿テキスト
  04_レビュー/              ← レビュー指摘・修正履歴

01_AgentCore-Runtime-ハンズオン/   ← 第2弾：Runtime実践記事
  （同上）
```

## 執筆フロー

1. `00_企画/` に方針メモ作成
2. `01_調査/` に技術調査ログ記録
3. `02_下書き/` で執筆（Obsidian）
4. `03_成果物/` に最終テキスト保存
5. `04_レビュー/` でレビュー記録
